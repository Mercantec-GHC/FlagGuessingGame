# FlagGuessingGame
vores project er et spil hvor man skal se et flag på arduino skærmen og vælge hvilket land der er fra, hvis man trykker på det rigtige land ud fra nogle valgmuligheder (arduino knapperne) for man +1 point og kan spille videre indtil man vælger et forkert svar hvor spillet slutter og man se ens highscore på hjemmesiden.
